│                         STEP 1: MONGODB ATLAS SETUP                          │
│                              (2 minutes)                                     │

└──────────────────────────────────────────────────────────────────────────────┘

    🌐 Go to: https://www.mongodb.com/cloud/atlas
    
    ✅ Sign up (free, no credit card)
    
    ✅ Create Cluster
       ├─ Choose: "Shared" (Free)
       ├─ Provider: AWS / Google / Azure (any)
       └─ Region: Closest to you
    
    ✅ Create Database User
       ├─ Username: admin (or your choice)
       ├─ Password: [Generate secure password]
       └─ Privileges: "Read and write to any database"
    
    ✅ Network Access
       ├─ Add IP Address
       └─ Select: "Allow Access from Anywhere" (0.0.0.0/0)
    
    ✅ Get Connection String
       ├─ Click: "Connect" → "Connect your application"
       ├─ Copy: mongodb+srv://admin:<password>@cluster0.xxxxx.mongodb.net/
       ├─ Replace: <password> with your actual password
       └─ Add: /login-module at the end
    
    📋 SAVE THIS:
    mongodb+srv://admin:YourPassword@cluster0.xxxxx.mongodb.net/login-module
                                    ↑↑↑↑↑↑↑↑↑↑↑
                              Replace with your password!

└──────────────────────────────────────────────────────────────────────────────┘

    🌐 Go to: https://vercel.com
    
    ✅ Sign up with GitHub
    
    ✅ Import Project
       ├─ Click: "Add New" → "Project"
       ├─ Select: Your GitHub repository
       └─ Click: "Import"
    
    ✅ Configure Settings
       ├─ Framework Preset: Other
       ├─ Root Directory: ./
       ├─ Build Command: (leave empty)
       ├─ Output Directory: (leave empty)
       └─ Install Command: npm install
    
    ✅ Add Environment Variables (CRITICAL!)
       
       Click "Environment Variables" and add these 4:
       
       ┌─────────────────────────────────────────────────────────────────────┐
       │ Name: MONGODB_URI                                                   │
       │ Value: mongodb+srv://admin:pass@cluster.mongodb.net/login-module    │
       │        ↑↑↑ Your connection string from Step 1                       │
       └─────────────────────────────────────────────────────────────────────┘
       
       ┌─────────────────────────────────────────────────────────────────────┐
       │ Name: SESSION_SECRET                                                │
       │ Value: 50e3989549d88d524071e0a7689f2206c0fd543ff58adca6bf2f4db...   │
       │        ↑↑↑ Your generated secret from Step 2                        │
       └─────────────────────────────────────────────────────────────────────┘
       
       ┌─────────────────────────────────────────────────────────────────────┐
       │ Name: GEMINI_API_KEY                                                │
       │ Value: AIzaSyDPXqA3NFBR33QdwzSsJj-tpYl8x5t2_dE                      │
       └─────────────────────────────────────────────────────────────────────┘
       
       ┌─────────────────────────────────────────────────────────────────────┐
       │ Name: NODE_ENV                                                      │
       │ Value: production                                                   │
       └─────────────────────────────────────────────────────────────────────┘
    
    ✅ Click "Deploy"
    
    ⏳ Wait 1-2 minutes...

                              🛠️ TROUBLESHOOTING

┌──────────────────────────────────────────────────────────────────────────────┐
│ Problem: Can't connect to database                                          │
│ Solution:                                                                    │
│   • Check MongoDB Atlas → Network Access → Allow 0.0.0.0/0                  │
│   • Verify MONGODB_URI in Vercel has correct password                       │
│   • Check cluster is running in MongoDB Atlas                               │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ Problem: Session keeps logging out                                          │
│ Solution:                                                                    │
│   • Verify SESSION_SECRET is set in Vercel                                  │
│   • Check NODE_ENV is set to "production"                                   │
│   • Clear browser cookies and try again                                     │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ Problem: AI not generating scenarios                                        │
│ Solution:                                                                    │
│   • Verify GEMINI_API_KEY in Vercel                                         │
│   • Check Vercel logs for API errors                                        │
│   • Verify API key is active and has quota                                  │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ Problem: 404 errors on pages                                                │
│ Solution:                                                                    │
│   • Check vercel.json exists in root                                        │
│   • Redeploy from Vercel dashboard                                          │
│   • Check Vercel logs for routing errors                                    │
└──────────────────────────────────────────────────────────────────────────────┘
